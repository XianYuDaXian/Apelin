Apelin 0.2.11 keeps a long conversation responsive after it has been reopened many times.

- Sending a message in a conversation that had been reopened many times could stop Apelin's background service from answering, because it kept a full copy of the conversation for every reopen. It now keeps only the latest one, and clears the copies earlier versions left the first time it starts.
- While a reply streamed, the whole conversation was written to storage again with every piece of it, which iOS could report as excessive disk writes. A conversation is now saved at most every three seconds while it streams, and at once when a turn starts or ends and when Apelin goes to the background.
- After a reboot or a new jailbreak on RootHide, a conversation trusted the paths it had used before and could spend a long turn looking for a toolchain and SDK that were still installed. The agent is now told the background service restarted, checks what is installed first, and no longer writes the bootstrap's path into project files.
- Build and package scripts the agent writes now stop when a variable in a path they remove is empty, rather than removing from the bootstrap's root.
- Edit in the Model Providers menu, and a few other labels, showed in English whatever the language. They are now translated.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
