Apelin 0.3.1 asks before the agent uses the screen, lets it use root and file issues when you ask, and keeps your place in a long conversation.

- The agent could open apps and links and read or tap the screen without asking. A new setting, Ask Before Using the Screen, on by default, makes it ask before each of these in every approval mode, whether through its own screen tools or icli. You can turn it off in Settings ▸ Permission Mode.
- Asked to find out why Irisin refused an install or update, the agent would not ask for root, even when you told it to. It can now run a step that needs root for a task you gave it, saying first what it runs and why. Outside Full mode each one still asks, and anything that deletes or changes files outside the project, a system setting or another package waits for your go-ahead for exactly that, in every mode.
- To report a problem to another project, the agent had no way but to drive Safari. It can now open an issue on a GitHub repository you name, with your GitHub sign-in, after showing you the repository and the whole text and getting your go-ahead.
- A feedback issue the agent filed could only be corrected by hand, or by filing another. The agent can now read and edit the feedback issues your account opened, showing you the change first, and it never overwrites an edit you made on GitHub in the meantime.
- Some conversations, such as a new one that had just started working, offered no Delete in the sidebar, or a Delete that did nothing. Every conversation can now be deleted from the sidebar and from the chat's … menu; one that is still working asks first and offers Stop and Delete.
- On an iPad, opening or closing the sidebar in a long conversation moved you away from what you were reading. You now stay on the same line.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
