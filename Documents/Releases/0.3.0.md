Apelin 0.3.0 lets the agent use the tool extensions you install, publishes release packages you already built, and keeps the sidebar still while conversations work.

- The Disassembler and Assembler extensions were installed and working, but no conversation could use them. The agent now has `disassemble`, `symbols` and `assemble`, and the tools of any other installed extension, in every conversation; one installed or removed while a conversation is open is picked up with your next message. In Strict mode each call asks first.
- To publish release packages you had already built, the distribution page made you build them again and warned that the version was already packaged. It now lists the release packages of the current version for each target, shows whether each is built, shared or published, and publishes the roothide and rootless packages together, exactly as they were built. The agent can publish them for you too, when you ask; in Strict mode it shows you what goes where first.
- After a distribution build, sharing or publishing the package was hidden in a menu. Distribute is now the page's main button, with Share Package and Publish to Repository, and Publish to Repository opens Settings ▸ Git when no package repository is set up yet.
- Conversations jumped around the sidebar whenever an agent wrote something. They now stay where they are, and move only when you start one or send a message.
- The agent could take screenshots without asking, catching other apps on the screen. It now asks before every screenshot, in every mode, saying what it is for, and otherwise reads the screen through its layout.
- A new project kept the `local.apelin.…` identifiers Apelin made up until release, when changing them made a different package. The agent now asks you for permanent package and bundle identifiers before the first install, and agrees a migration with you before it changes one that is installed.
- Packages built from Apelin's templates had no icon in package managers. New projects now carry their project type's icon, which you can replace with your own.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
