Apelin 0.2.8 lets the agent create a GitHub repository and delete another project when you ask it to.

- Asking the agent to put a project on GitHub failed, because it could not create a repository. It can now create an empty public or private repository on your account or an organization, with the name and visibility you give, and then push to it. In Strict mode it asks every time.
- To delete a project, the agent had to tap through Apelin's own screens. It can now delete another project when you ask, with its files and conversations; in Strict mode it asks every time and says the deletion cannot be undone. A conversation never deletes its own project.
- Conversations of a project whose folder was removed outside Apelin stayed in the list and opened nothing. They are now removed.
- In Full mode, the agent's rename of another project waited for an approval that never came. It now goes through, as in Relaxed mode.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
