Apelin 0.2.7 makes long chats open at once and never stick on "Thinking…", keeps the messages you send while the agent works, and lets the agent see images, wake the screen, read web pages and send feedback when you agree.

- A long chat could take minutes to open, say the background service was not responding, and then stay on "Thinking…". It now opens at once, a retry no longer starts the chat a second time, and a run that stops is always shown as stopped. Streamed replies are also stored in far fewer pieces, so chats stay quick as they grow.
- Messages sent while the agent was working could be lost when its run ended or was stopped. A run that ends now goes on with them, and a stopped run puts them back in the composer ahead of what you have typed since.
- The agent could not look at an image in the project or show you a file. It now sees pictures it reads, and can show you project files in the chat, opening in Quick Look.
- The agent could not check its work while the screen was off or locked. It can now wake the screen and press Home or Lock; on a device with a passcode it asks you to unlock it and never asks for the passcode.
- The agent could tap around inside Apelin itself. Its screen actions now never reach Apelin.
- A dropped connection failed the agent's turn. It now waits for the network to come back and shows "Reconnecting…".
- Installing a package that clashed with another one only showed the installer's message. Apelin now says which package is in the way and how to clear it, and the agent can list what Apelin installed and remove a package by its name.
- Commands such as clang, nm and otool could not be run by name. The agent now finds the toolchain's tools by name, and takes a path too.
- A tweak for an app other than SpringBoard could not be created with its filter set. The filter now takes a list of apps the first time.
- The agent had no way to read a web page except through the shell. It can now read a public page as text.
- The agent can now report a problem as a GitHub issue on Apelin with your GitHub sign-in, only after showing you what it would send and you agree.
- Headers of private frameworks were not found unless asked for, and a header named after a class could be missing. The framework tools now look in PrivateFrameworks too and find the header that declares a class.
- A misspelled field in a project's description gave an error that did not say where. The error now names the field and where the description's schema is.
- The agent could not read the headers that ship with Apelin's development extensions or the SDKs. It can now read them, without being able to change them.
- The agent could only manage memories of the current project. It can now see and manage another project's memories too, and General Chat can list and read the other conversations.
- Files attached to a chat showed up as changes in the project's git, and a project without a repository only answered "not a git repository". Attachments are now left out of git, the agent can add a remote, and it is told to create the repository first.
- A command-line tool built from the template could not use the GPU or create images in memory. New command-line projects now carry the entitlements for it.
- Removing a toolchain left empty folders behind on RootHide. They are now removed.
- After reinstalling an app, the running copy kept the old build. The agent is now told to restart it.
- The agent's progress notes could switch to English in a Chinese chat, it said a change was finished without having tried it, and it refused to show its instructions. It now keeps to your language, says what it has not tested, and shows its instructions when you ask.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
