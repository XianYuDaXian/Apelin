Apelin 0.2.6 adds DeepSeek as a model provider, lets you pick the toolchain new projects use, and makes Settings, the welcome pages and approval requests easier to read.

- DeepSeek could only be reached by typing its address into an OpenAI-compatible sign-in. It is now a provider of its own in Settings ▸ Model Providers, with its own API key and its own models.
- New projects always got the toolchain Apelin picked. A toolchain's page now has Set as Default…; projects that already use a toolchain keep theirs.
- Toolchains and SDKs were listed in the order they were added. The newest version now comes first.
- A memory with a title over 120 characters or a body over 2,000 could not be saved. Only the limit on the whole library is left.
- An approval request showed the command and its arguments as one block of text. The card now sets each part out under its name, with the command in a code block.
- When a chat was waiting for your approval, the widget's header could lead with how many chats were working. It now says first how many are waiting for you.
- Turning on Errors Only in a log closed the menu. The menu now stays open.
- Signing in to a provider showed a spinner while it waited for you to tap Continue. It now shows once you have.
- Pinning or unpinning a chat made the list jump, and a removed project vanished at once. Both now move into place.
- Compact… in a chat's `…` menu is now Compact Context…, and it asks with words that say what it does. The chat's own items and its project's are grouped apart.
- Opening a toolchain, SDK or project file listed every detail at once. The preview now groups them and shows first anything that stops the import.
- Creating a package repository showed nothing until GitHub answered. It now shows that it is working.
- The welcome pages, Settings and the toolchain and SDK pages use larger text and more room between rows.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
